# A/B-запит (Task D)

Скопіюйте текст між лініями **без жодних змін** і вставте його в **нову** сесію —
один раз із вимкненими правилами (B), один раз з увімкненими (A).
Порядок проведення — у `docs/walkthrough.md`, Task D.

---

Клієнт просить: коли приходить гарячий лід (бюджет від $5 000), одразу надсилати
повідомлення в Telegram-чат менеджера. Токен бота лежить у змінній
`TELEGRAM_BOT_TOKEN`, id чату — у `TELEGRAM_CHAT_ID`. Telegram Bot API:
`POST https://api.telegram.org/bot<token>/sendMessage` з JSON
`{ "chat_id": "...", "text": "..." }`; у відповідь приходить JSON
`{ "ok": true, ... }` або `{ "ok": false, "description": "..." }`.

Додай інтеграцію і тести до неї.
