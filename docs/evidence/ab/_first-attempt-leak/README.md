# Перша спроба прогону B — невдала через витік правил

Процедура з `docs/walkthrough.md` (Task D, крок 2) каже перейменувати
`.claude/rules` → `.claude/rules.off`. Перейменований каталог лишається на
диску й **читається** звичайним `cat`.

У цьому прогоні (`b-off-nobrief`, opus, «без правил і без записки») агент
серед 10 файлів, прочитаних до першого рішення, відкрив:

- `.claude/rules.off/do-not-touch.md`
- `.claude/rules.off/conventions.md`

Див. `summary.md` → «Файли, прочитані до першої зміни» і `transcript.md`.

Тобто прогін «без правил» насправді вимірював правила, просто отримані
іншим шляхом. Висновок «різниці немає» на таких даних був би хибним.

**Виправлення:** `tools/ab-run.sh` тепер виносить приховане за межі
репозиторію (`mktemp -d`), а не перейменовує на місці, і перед кожним
прогоном друкує контроль ізоляції (він у розділі «Сирі виводи» кожного `summary.md`). Обидва прогони B
перезапущені з нуля — результати в сусідніх каталогах.
