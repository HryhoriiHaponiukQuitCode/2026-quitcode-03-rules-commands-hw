# Діфи прогонів A/B

| Файл | Прогін | Розмір |
|---|---|---|
| `b-rules-off.diff` | B без правил, `opus`, у репозиторії з git-історією | **порожній** — агент зупинився, нічого не змінив |
| `a-rules-on.diff` | A з правилами, `opus` | **порожній** — агент зупинився, нічого не змінив |
| `clean-rules-off.diff` | контроль: копія без git-історії, **без** правил | **є зміни** — 2 файли + новий каталог `src/leads/` |
| `clean-rules-on.diff` | контроль: та сама копія, **з** правилами | **порожній** — агент зупинився |

Порожні діфи — це результат, а не пропуск: у репозиторії з git-історією обидва
прогони закінчились зупинкою. Чому так і чому це не означає «правила не
працюють» — у `docs/ab-validation.md`.

Повні сліди всіх десяти прогонів (запит, транскрипт, числа) — у
`docs/evidence/ab/`.
