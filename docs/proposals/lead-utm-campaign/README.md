# Запит на зміну ядра: `Lead.utmCampaign`

Статус: **чекає на рішення платформної команди.** Робоче дерево не змінене.

## 1. Що саме треба змінити

`app/src/core/types.ts`, інтерфейс `Lead` — одне нове **необов'язкове** поле:

```ts
/** UTM-кампанія з форми сайту, напр. `spring_sale`. Може бути відсутня. */
utmCampaign?: string;
```

Решта зміни — поза ядром і чекає на це поле:
`app/src/integrations/sheets-append.ts` додає `lead.utmCampaign ?? ""` останньою
колонкою рядка, `sheets-append.test.ts` фіксує обидва випадки.

## 2. Навіщо — яка вимога без цього не закривається

Клієнт (Studio Nova) хоче бачити в Google-таблиці рекламну кампанію ліда. Форма
сайту вже передає `utmCampaign`. Таблиця — система обліку, тому за конвенцією §8
повні дані ліда туди йдуть. Кампанія доїжджає до інтеграції тільки всередині
`Lead`: `Integration.send(lead: Lead)` — єдиний канал, іншого параметра в
контракті немає.

## 3. Кого зачіпає

`core/` спільний для всіх клієнтських воркерів агенції. Поле необов'язкове, тож
зміна зворотно сумісна: наявні воркери, фікстури й виклики `send()` компілюються
без правок. Публічний API ядра (таблиця в `materials/architecture-brief.md`)
розширюється, не ламається.

Разом зі злиттям треба перегенерувати `app/scripts/core.lock.json` — інакше
`npm run check:rules` показуватиме `core-untouched  src/core/types.ts  modified`.

## 4. Який обхід можливий без зміни ядра і чому він гірший

- **Локальний тип `LeadWithCampaign extends Lead` в `integrations/`** — потребує
  звуження `Lead` кастом або guard'ом на кожному вході. Поле лишається невидимим
  для інших інтеграцій і для коду, що будує лід із форми, тобто заповнювати його
  однаково нікому. Прямо заборонено `.claude/rules/do-not-touch.md`.
- **`(lead as any).utmCampaign`** — порушує конвенцію §6 (без `any`) і ховає
  відсутність поля від компілятора.
- **Окрема мапа `id -> campaign` через `sync/`** — `integrations/` нічого не
  знають про `sync/`, це ламає напрям залежностей із записки.

Жоден із трьох не дешевший за один рядок у `Lead` — вони лише переносять борг у
місце, де його не видно рев'ю.

## 5. Готовий патч

`utm-campaign.patch` — усі три файли, застосовується з кореня репозиторію:

```bash
git apply docs/proposals/lead-utm-campaign/utm-campaign.patch
cd app && node scripts/check-rules.mjs --write-lock   # платформна команда, у своєму PR
npm test && npm run typecheck && npm run check:rules
```

Перевірено на ізольованій копії `app/` (поза захищеними шляхами):
`vitest run` — 27/27 пройдено (було 26), `tsc --noEmit` — чисто,
`check:rules` — лише очікуваний `core-untouched` плюс успадкований
`json-via-parse` у `src/sync/state.ts`.
