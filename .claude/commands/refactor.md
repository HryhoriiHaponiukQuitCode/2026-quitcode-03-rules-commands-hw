# Рефакторинг до конвенцій

**Ціль:** $ARGUMENTS
(Якщо в рядку вище немає конкретного файлу — ціль вказана в повідомленні
одразу після назви команди. Немає й там — спитай і зупинись.)

## Кроки

1. **Зафіксуй «до»** — виконай і збережи вивід у відповідь:
   ```bash
   cd app && npm test
   cd app && npm run check:rules
   ```
   Випиши окремо кількість порушень **саме для цільового файлу** (блок «by file»).
2. Прочитай цільовий файл і його тест поруч (`<ім'я>.test.ts`). Тест — це
   **специфікація поведінки**: URL, тіло запиту, тексти помилок, порядок викликів.
3. Прочитай сусідній модуль, який уже відповідає конвенціям
   (`app/src/integrations/slack-notify.ts`), — як зразок форми, не як шаблон
   для копіювання.
4. Перепиши цільовий файл за `.claude/rules/conventions.md`. Правила не
   переписуй сюди — застосовуй. Змінюй **лише** цільовий файл; якщо бракує
   типу чи хелпера з `core/` — див. Stop.
5. **Зафіксуй «після»** тими самими двома командами. Порівняй числа.
6. Покажи `git diff --stat` і поясни в 2-3 реченнях, що збереглось у поведінці:
   той самий URL, те саме тіло запиту, ті самі тексти помилок.

## Acceptance criteria

- [ ] `npm test` зелений **до** і **після**; кількість тестів не зменшилась.
- [ ] Жоден асерт у тестах не відредаговано. `git diff -- '*.test.ts'` містить
      лише додані тести, якщо взагалі щось містить.
- [ ] `check:rules` для цільового файлу: число **зменшилось**; TOTAL по проєкту
      не виріс.
- [ ] `git status --short` містить лише цільовий файл (+ його тест, якщо додавав тести).
- [ ] Зовнішня поведінка не змінилась: URL, тіло запиту, тексти помилок,
      сигнатура експорту — ті самі.
- [ ] `cd app && npm run typecheck` без помилок.

## Stop

- Зупинись, **якщо для рефакторингу треба правити тест**: якщо асерт більше не
  проходить, змінилась поведінка — це вже не рефакторинг. Покажи, який асерт і
  чому, і чекай рішення.
- Зупинись, якщо потрібен новий експорт із `app/src/core/**`, — оформи за
  `.claude/rules/do-not-touch.md` (що, навіщо, кого зачіпає, який обхід).
- Зупинись, якщо бракує залежності: нових пакетів не додаємо
  (`.claude/rules/conventions.md` §7).
- Не чіпай нічого, крім цільового файлу та його тесту.
